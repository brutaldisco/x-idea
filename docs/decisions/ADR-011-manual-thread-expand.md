# ADR-011: セルフスレッドは Reader で押した Source だけ取得・表示する

- 日付: 2026-09-06
- 状態: 採用
- 関連: 設計書 8.5 / 14.5 / T-509、ADR-005

## 文脈

同期時に起点投稿へ `expand_thread` を自動投入すると、Post read $0.005/件が全件に乗る。Reader も `conversation_id` 一致の同一著者投稿を、展開依頼なしに「セルフスレッド」として出していた。

## 決定

- 同期は `expand_thread` を投入しない。投入は Reader の「セルフスレッドを取得」のみ。
- 表示は展開済みのときだけ。目印は起点の `thread_root_id == tweet_id`（成功時に立てる）。過去の自動展開は、当該起点で保存した連投の有無で判定する。
- 未展開の会話内投稿は出さない。返信（他著者）の自動表示は変えない。
- `thread_expand_enabled` は既定 OFF のまま。人間の指示なしに ON にしない。

## 影響

- 設計書 14.5 とジョブ表のトリガーを「Reader 手動」に合わせる。
