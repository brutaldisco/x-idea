# ADR-014: 既定の X アカウントを Settings で選ぶ

- 日付: 2026-09-07
- 状態: 採用
- 関連: ADR-003、設計書 8 / 10 / 19 / T-101c

## 文脈

ADR-003 は Cookie `x_ctx` が無いとき **先頭アカウント**（`created_at` 昇順）を開く。先頭が取り込み中のアカウントだと、別ブラウザや初回表示で意図しない方のライブラリが出る。既定を Settings で選びたい。

## 決定

- `settings.default_x_account_id` に既定アカウントを保存する。シングルトン設定。`user_id` は追加しない。
- 閲覧スコープの解決順は **有効な `x_ctx` → 既定 → 先頭アカウント**。
- Settings のアカウントカードで、選択中アカウントを既定にできる。既定にしたときは、今の Cookie も同じアカウントに合わせる。
- 連携解除でその ID が既定なら、既定を空に戻す。
- 初回マイグレーションは、既存の `@Deathisnotf1nal` があればそれを既定にする。以後は Settings の値が正。

## 影響

- Cookie を持つブラウザは、切替結果をこれまでどおり保持する。
- Cookie が無い表示（別ブラウザ・初回）は、Settings の既定を開く。
- ADR-003 の「未設定は先頭」は、既定が空のときの最終フォールバックとして残す。
