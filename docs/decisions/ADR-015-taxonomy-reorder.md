# ADR-015: Settings の分類をハンドルで並べ替える

- 日付: 2026-09-08
- 状態: 採用
- 関連: 設計書 8.7 / 10 / 21 / T-211、`account_taxonomy.sort_order`

## 文脈

分類（カテゴリ／情報タイプ）はアカウントごとに持てるが、順は seed のまま固定だった。Library の絞り込みもこの順なので、よく使う項目を上へ寄せたい。どのアカウントの分類かが一覧だけでは分かりにくい。

## 決定

- Settings の分類見出しに、表示中アカウントの `@ハンドル` を出す。
- 各行の左にドラッグハンドルを出す。ポインタのドラッグと、ハンドルにフォーカスした矢印キーで並べ替える。
- 順は `account_taxonomy.sort_order` に保存する。共有の `categories.sort_order` は触らない（seed の `item_id` を複数アカウントが共有するため）。
- `PATCH /api/settings/taxonomy` に `item_ids` を足す。いまの一覧の順列だけを受け付ける。

## 影響

- Library のカテゴリ／情報タイプの選択肢は、Settings で並べた順になる。
- 追加・改名・削除の API は変えない。
