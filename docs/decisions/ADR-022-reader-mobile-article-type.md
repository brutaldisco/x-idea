# ADR-022: モバイル Reader の左右余白を詰め、記事本文は 0.9375rem / 字間 0.06em にする

- 日付: 2026-09-14
- 状態: 採用
- 関連: 実装設計書 8.5 / 10.2、`docs/design/2026-09-12-reader-readability.md`、T-220 / T-221

## 文脈

T-220 で Reader 本文を `.reader-body`（1.05rem / 1.85 / 40em）に揃え、モバイルはページ `px-3`・記事カード `p-3`・原文カード `px-5` とした。実機ではページ余白とカード余白が重なり、原文・要約カード（`px-5` / `p-5`）が特に狭く、記事本文も 16.8px だと字間が詰まって長く読みにくい。

## 決定

1. **モバイルの左右余白をページ `0.5rem`＋カード `0.5rem` に揃える。** 対象は Reader ページ、`PostBlock`、`ArticleBlock`、要約カード、セグメントバーのネガティブマージン。`min-[48rem]` 以上の `2rem` は変えない。
2. **記事本文だけ** `.article-body` で **0.9375rem（15px）** と **`letter-spacing: 0.06em`** にする（2026-09-14 追記: 当初の 1rem / 0.03em から、実機の読みやすさに合わせて一段小さく・字間を広げる）。原文 `.reader-body` は 1.05rem のまま。Chrome 翻訳の記事対訳も同じクラスを当てる。

## 影響

- 375px 幅では本文の実効幅が約 24〜32px 広くなる（原文カードが最も効く）。
- 記事は原文より一段小さく、字間がわずかに開く。見出しは `em` 指定のため追従する。
- 原文カラム・AI 列・DB は触らない。
