# ADR-003: アカウントコンテキスト（ビュー切替）で混ぜない

- 日付: 2026-09-05
- 状態: 採用
- 関連: ADR-002、設計書 8.1 / 18.1 / 35 章 T-101c

## 文脈

ADR-002 で X 連携を最大 3 アカウントにしたが、初期案では Today / Inbox / Library / Ask が全アカウントを混ぜて表示していた。ユーザーから「指向性の異なる 2 つのアカウントを混ぜたくない」と明確な要望があった。続けて、切替 UI はフッター内の現在アカウント名から開き、「すべて」は不要と指示された。

## 決定

- **アカウントコンテキスト**を導入する。閲覧スコープは常に **選択中の 1 アカウント**。
- 「すべて」は持たない。Cookie 未設定や無効値は **先頭アカウント** にフォールバックする。
- コンテキストは HttpOnly Cookie `x_ctx` に保持する。URL クエリには載せない。
- フッター（タブバー）の上段に現在の `@name` を出す。タップで「アカウントを切り替える」と候補一覧を開く。
- `sources.x_account_id` が `NULL`（手動保存・解除済み由来）は表示しない。
- 物理的な帰属は `sources.x_account_id` のまま。`user_id` は追加しない。
- 同期・AI 予算・ジョブはアカウント横断のまま（コンテキストは閲覧スコープのみ）。

## 影響

- Today / Inbox / Library / Ask は選択中アカウントの Source だけを見せる。
- Settings のアカウント管理は全件表示のまま。切替 UI はフッター共通。
- 切替は即時反映（`router.refresh()`）。
