# ADR-003: アカウントコンテキスト（ビュー切替）で混ぜない

- 日付: 2026-09-05
- 状態: 採用
- 関連: ADR-002、設計書 8.1 / 18.1 / 35 章 T-101c

## 文脈

ADR-002 で X 連携を最大 3 アカウントにしたが、v3.2 時点では Today / Inbox / Library / Ask が全アカウントの Source を混ぜて表示する設計だった。ユーザーから「指向性の異なる 2 つのアカウントを混ぜたくない」と明確な要望があった。

## 決定

- **アカウントコンテキスト**を導入する。閲覧スコープは「すべて / @a / @b / @c」のいずれか 1 つ。
- コンテキストは HttpOnly Cookie `x_ctx` に保持し、タブバー直上のアカウントピルで切り替える。URL クエリには載せない（ブックマークや共有で意図せずコンテキストが変わるのを防ぐ）。
- 既定は「すべて」。`sources.x_account_id` が `NULL`（手動保存・解除済み由来）は「すべて」のときだけ表示する。
- 物理的な帰属は `sources.x_account_id` のまま。`user_id` は追加しない。
- 同期・AI 予算・ジョブはアカウント横断のまま（コンテキストは閲覧スコープのみ）。

## 影響

- Today の同期ピル（最終同期・AI 処理待ち）は選択中アカウントに絞る。
- Inbox 件数、Library 一覧、Ask の検索対象は選択中コンテキストでフィルタする。
- Settings は全アカウントを常に表示する（管理画面のためコンテキスト非依存）。
- 切替は即時反映（`router.refresh()`）。キャッシュキーにコンテキストを含める。
