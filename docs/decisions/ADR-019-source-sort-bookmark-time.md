# ADR-019: 一覧の時刻並びは X のブックマーク順にする

- 日付: 2026-09-12
- 状態: 採用
- 関連: 設計書 8.3 / R-10 / P-12、`src/lib/source-sort.ts`

## 文脈

Library / Inbox の「新しい順」は投稿日時（`posted_at`）だった。X のブックマーク画面は、投稿日ではなく **ブックマークした順**（新しいブックマークが上）である。ユーザーはその順を覚えている。

X Bookmarks API はブックマーク時刻を返さない（R-10）。返るのは投稿オブジェクトと、新しいブックマークからの並びだけである。

## 決定

- 時刻並びは **新しい順 / 古い順** のみ。ラベルに「保存が」は付けない。
- キーは初回観測時刻 `saved_at`（P-12）。これがブックマーク日の近似。
- 同期は API と同じく新しいブックマークから INSERT する。同秒のタイブレークは新しい順が `id ASC`、古い順が `id DESC`。
- `?sort=` の id は互換のため `posted_desc` / `posted_asc` のまま。`saved_asc` は古い順。
- 「動画の保存済み」は残す。同グループ内も `saved_at`。
- 新規取り込みの `bookmarked_at` は投稿日時ではなく、観測時刻（`datetime('now')`）を入れる。

## 影響

- 昔の投稿を昨日ブックマークすれば、新しい順の先頭付近に出る。
- 過去分をまとめて取り込んだ場合、その一括の `saved_at` が観測時刻になる。X 上の本当のブックマーク日より新しく見えることがある。
- カードに出す日付は従来どおり投稿日（`posted_at`）。
